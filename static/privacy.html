Privacy Policy — ServiceNow Ticket Recommender

An independent tool built by a Rutgers OIT team member for internal team use.

1. What this extension does

The ServiceNow Ticket Recommender is a Chrome extension, built independently by a Rutgers OIT team member, used by their team's help desk staff. It reads the currently open ServiceNow incident ticket's description and work notes, and displays AI-generated, knowledge-base-grounded resolution suggestions in a side panel alongside the ticket.

2. What data is read

The extension reads ticket text — the incident description and work notes — only from the active ServiceNow tab, and only when the user clicks “Analyze.” It does not run in the background, and it does not read any other page or tab.

3. What is redacted before anything is sent

Before any ticket text leaves the browser, the extension automatically redacts sensitive identifiers, including:

  • IP addresses
  • Email addresses
  • RcpID values
  • NetID values
  • Other ID-like patterns

This redaction happens locally in the browser, before any network request is made.

4. What is transmitted, and to whom

The redacted ticket text is sent over HTTPS to a backend server operated by the tool's developer at servicenow.smafnanhaider.com, authenticated with a private API key. That backend forwards the redacted text to a third-party LLM API (DeepSeek) solely to generate the resolution recommendation, and returns the result to the extension. No other third party receives this data.

5. What is not stored

The backend does not log, save, or persist ticket text anywhere. Each request is processed and its result returned; no ticket data is retained on the server after the response is sent.

6. Who can use this extension

This extension is distributed privately to a small group of trusted colleagues, via a private (non-public) Chrome Web Store listing. It is not available to the general public.

7. Data retention

No user data is retained by the extension itself. It holds ticket data in memory only while the side panel is open, and does not use browser storage (localStorage, cookies, etc.) to persist any ticket content.
